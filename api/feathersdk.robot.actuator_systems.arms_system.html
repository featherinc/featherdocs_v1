class feathersdk.robot.actuator_systems.arms_system.Robstride7MArm(config, *args, **kwargs)¶

set_targets(positions=None, max_velocities=None, max_accelerations=None, max_jerks=None, kps=None, kds=None, target_velocities=None, target_accelerations=None, additional_torques=None)¶

Sets the target values for one or more motors in the arm.

Motion is controlled using Robstride’s Operation Command mode. Each arm motor will apply torque according to the following formula:

torque = kp * (target_position - current_position) + kd * (target_velocity - current_velocity) + offset

Where:

  • target_position is the target position angle to reach.

  • current_position is the last-received position angle of the motor.

  • target_velocity is the target angular velocity to reach. (This is computed automatically. See below.)

  • current_velocity is the last-received angular velocity of the motor.

  • kp is the proportional gain, applied to the position error.

  • kd is the derivative gain, applied to the velocity error.

  • offset is extra torque applied as needed. It will consist of: * Gravity compensation if config.apply_gravity_compensation is True. * Plus any additional torque to apply in the offset parameter to this function call.

Motor telemetry should update at around config.operating_frequency Hz.

The target velocity is computed automatically for time-optimal motion planning using Ruckig.

NOTE: Values will be clamped to the motor’s limits before sending commands to the motor. EG: using a max_velocity higher than the motor’s config.max_velocity will be clamped to the motor’s config.max_velocity.

NOTE: All parameters are optional. If None, then none of the motors’ parameters for that value will be changed. Otherwise it should be a dictionary with keys being either 1) the string name of the motor or 2) the RobstrideMotor object itself. Values are the new target values for that parameter. Any missing motor keys will not have their parameters changed. Any parameter values that are None will not be changed.

NOTE: If the arm is not in target control mode, then there may be restrictions on which parameters can be set. If in Impedance control mode, then only kps, kds, and additional_torques can be set.

Parameters:

  • positions (Dict[str | RobstrideMotor, float] | None) – New target position angles. See Note above for format details.

  • max_velocities (Dict[str | RobstrideMotor, float] | None) – New target maximum velocities. See Note above for format details.

  • max_accelerations (Dict[str | RobstrideMotor, float] | None) – New target maximum accelerations. See Note above for format details.

  • max_jerks (Dict[str | RobstrideMotor, float] | None) – New target maximum jerks. See Note above for format details.

  • kps (Dict[str | RobstrideMotor, float] | None) – New proportional gains. See Note above for format details.

  • kds (Dict[str | RobstrideMotor, float] | None) – New derivative gains. See Note above for format details.

  • target_velocities (Dict[str | RobstrideMotor, float] | None) – New target velocities. These are the velocities we want the motors to have when reaching the target position. Set to 0 to have motor stop at target position. See Note above for format details.

  • target_accelerations (Dict[str | RobstrideMotor, float] | None) – New target accelerations. These are the accelerations we want the motors to have when reaching the target position. Set to 0 not have instantaneous acceleration change upon reaching target. See Note above for format details.

  • additional_torques (Dict[str | RobstrideMotor, float] | None) – New additional torques to apply. See Note above for format details.

Return type:

None
