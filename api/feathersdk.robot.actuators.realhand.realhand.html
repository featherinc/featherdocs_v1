feathersdk.robot.actuators.realhand.realhand Module¶

RealHand O6 dexterous hand driver for FeatherSDK.

Protocol (reverse-engineered from RealHand/core/can/real_hand_o6_can.py):

  • Standard (11-bit) CAN frames.

  • Arbitration id is the hand id: 0x27 for the right hand, 0x28 for the left.

  • data[0] is the “frame property” (the command/register), data[1:] is the payload. Sending a frame property with an empty payload is a query; the hand replies with a frame whose data[0] echoes the frame property.

Frame properties used here:

Property

Meaning

Direction

0x01

joint positions (6 x 0-255)

set / query

0x02

torque limits (6 x 0-255)

set / query

0x05

speeds (6 x 0-255)

set / query

0x20

normal pressure

query

0x21

tangential pressure

query

0x22

tangential pressure direction

query

0x23

proximity / approach induction

query

0x33

motor temperatures

query

0x35

motor fault codes

query

0x36

motor currents

query

0x64

firmware/embedded version (alt 0xC2)

query

Joint order (per RealHand docs) is:

[thumb_flexion, thumb_abduction, index, middle, ring, pinky]

All joint/speed/torque values are 0-255 where, for positions, 255 is fully open and 0 is fully closed.
