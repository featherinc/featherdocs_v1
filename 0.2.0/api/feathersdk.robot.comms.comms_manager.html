teensy_ip: str¶

The IP address of the Teensy host.

teensy_port: int¶

The port of the Teensy host.

teensy_operating_frequency: float¶

The frequency at which the comms manager will attempt to process results from the teensy socket.

teensy_telemetry_update_frequency: float¶

The frequency at which the comms manager will attempt to request motor telemetry updates from the Teensy.

teensy_candump_update_frequency: float¶

The frequency at which the comms manager will attempt to request candump updates from the Teensy.

enable_teensy_debug_logging: bool¶

Whether to enable debug logging from the Teensy over serial.

teensy_correct_clock_drift: bool¶

Whether to correct the clock drift of the Teensy.

teensy_board_clock_sync_hz: float¶

The frequency at which the comms manager will attempt to sync the Teensy clock to the host clock.

teensy_expected_clock_drift_ns: int¶

The expected clock drift of the Teensy in nanoseconds per second. This is used to determine when we will update the clock offset on the Teensy to re-sync the clock to the jetson.

teensy_max_clock_sync_error_ns: int¶

The maximum error in nanoseconds between the Teensy and host clocks that is acceptable for clock sync.

teensy_clock_sync_trials: int¶

The number of trials to attempt to sync the Teensy clock to the host clock.

teensy_check_unused_messages_interval: float¶

The interval in seconds to check for unused message responses.

teensy_max_rx_messages_per_tick: int¶

The maximum number of message responses to process per tick.

use_emulated_teensy: bool¶

Whether to use the emulated Teensy running on the host machine instead of a real connected Teensy 4.1 board. This requires you to have the can usb devices connected to the host machine.

max_can_rate: float¶

The maximum messages per second that can be sent on a CAN interface. Sent to the Teensy on initialize and used for host-side CAN rate limiting.

can_leniency: float¶

Leniency for CAN bus overload checks. Must be <= max_can_rate. Sent to the Teensy on initialize.

server_run_time_nanos: int¶

Max time in nanoseconds the Teensy may spend servicing the ethernet server loop per tick. Sent on initialize.

can_read_run_time_nanos: int¶

Max time in nanoseconds the Teensy may spend polling CAN buses per tick. Sent on initialize.

result_operating_frequency: float¶

The frequency at which the comms manager result processing thread will attempt to process results from the socket result buffer.

await_thread_start_timeout: float¶

The timeout in seconds to wait for the processing thread to start.

processing_toggle_timeout: float¶

The timeout in seconds to wait for the processing thread to toggle processing when making changes to the processing state.
